# Storm dashboard (live JMA data)

แดชบอร์ดดึงข้อมูลพายุจาก **Japan Meteorological Agency (JMA), RSMC Tokyo** ทุกครั้งที่เปิดหน้า, ทุก 5 นาที และเมื่อกลับมาเปิดแท็บอีกครั้ง

## ความสามารถล่าสุด

- แสดงพายุ Active จากรายงาน JMA ภายใน 24 ชั่วโมงล่าสุด
- แสดง **Storm Track Forecast ล่วงหน้า 3–5 วัน** ด้วยจุดศูนย์กลางพายุจาก JMA
- เส้นทึบ = ตำแหน่งล่าสุด, เส้นประ = จุดพยากรณ์
- แสดงพิกัด เวลา ประเภทพายุ ความเร็วลม ความกดอากาศ และรัศมีวงกลมความน่าจะเป็นเมื่อมีข้อมูล
- ใช้ข้อมูลสำรองเดิมหาก JMA หรือเครือข่ายขัดข้อง

## เริ่มใช้งาน

```bash
cd tropical_cyclone_names
python3 server.py --port 8000
```

จากนั้นเปิด `http://127.0.0.1:8000/` หรือ URL ของเซิร์ฟเวอร์ที่นำไป deploy

- `/api/storms` เป็น same-origin proxy สำหรับ JMA JSON feed และปิด browser cache
- ข้อมูล forecast อิง JMA/RSMC Tokyo และเป็นแนวทาง ไม่ใช่ขอบเขตพื้นที่อันตราย
